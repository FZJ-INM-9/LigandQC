===============
How to Get Help
===============

If you need help with the project, the best place to start is the documentation in this site.
For installation and first-time setup, see :doc:`installation`.
For the main workflow and examples, see :doc:`tutorials` and :doc:`cli`.
For common questions and troubleshooting, see :doc:`faq` and :doc:`known_issues`.

If you still need support, please open an issue on the GitHub issue tracker:
https://github.com/brgstfzj/LigandQualityScraper/issues

When creating an issue, include:

* a short description of the problem or question,
* the command or code snippet you ran,
* the expected result and the actual result,
* relevant warnings, error messages, and version information.

This makes it much easier for maintainers to reproduce and fix the problem quickly.
